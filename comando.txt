# 1. Atualizar a branch develop no GitHub com os últimos commits (incluindo o amend do .gitignore)
git push --force-with-lease origin develop
git push --tags --force

# --- Ações no GitHub ---
# Faça o Pull Request ou Merge da branch `develop` para `main` pela interface do GitHub.

# 2. Após concluir o merge no GitHub, sincronize a branch main localmente:
git checkout main
git pull origin main
git checkout develop
